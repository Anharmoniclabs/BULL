Measured boundary

BULL governs access to synthetic HTTP assets. The sensor has no command executor, outbound broker, real credentials, or KVM workload. Allowed does not mean a file existed or that a response reached its recipient.

Source IP is unavailable through the local relay. Forwarded headers are not trusted. Traffic alone does not establish AI-agent or botnet identity. This deployment uses a local authenticated audit checkpoint, not an external receipt.

Limits: 8 KiB request body; first 2 KiB retained; 4,000 ledger records; bounded run duration. Relay drops and pre-parser failures are not a complete packet capture.
